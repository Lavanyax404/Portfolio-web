# 🌟 Modern 3D Developer Portfolio
This is a modern, animated 3D developer portfolio designed to help you make a standout impression and creatively showcase your skills. It combines powerful 3D visuals with smooth motion effects for a truly engaging user experience.

# ✨ Core Features
🔥 Immersive 3D Graphics: Built using React Three Fiber and Drei for high-performance 3D rendering directly within React.

⚡ Fluid Animations: Incorporates Framer Motion for smooth transitions and compelling scroll-based animations.

🎨 Sleek & Responsive Design: A clean, mobile-friendly user interface powered by the utility-first framework, TailwindCSS.

💌 Functional Contact Form: Features a working contact mechanism through easy EmailJS integration.

🧱 Enhanced UI Components: Utilizes high-quality, prebuilt components from Aceternity UI and Magic UI for beautiful design enhancements.

🚀 Blazing-Fast Development: Expedited and optimized with the lightning-fast build tool, Vite.

---

## 🛠 Tech Stack

| Tech              | Description                           |
|-------------------|---------------------------------------|
| React             | Front-end JavaScript library          |
| Vite              | Fast bundler and dev environment      |
| TailwindCSS       | Utility-first CSS framework           |
| React Three Fiber | 3D rendering with Three.js in React   |
| Drei              | Helpers and abstractions for R3F      |
| Framer Motion     | Animation library for React           |
| EmailJS           | Form handling and email integration   |
| Aceternity UI     | Custom UI components                  |
| Magic UI          | Prebuilt UI elements and design extras|
